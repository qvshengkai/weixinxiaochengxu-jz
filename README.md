# 记账小程序 · 可运行 MVP 工程

原生微信小程序 + 云开发（CloudBase）。本工程实现了「极简记账流 + 语音记账 + 统计报表（环比/同比/占比/预算）+ 微信账单导入」的 MVP，导入微信开发者工具即可真机调试。

> ⚠️ **合规前提**：微信不向第三方小程序开放「读取用户个人微信支付账单」的 API。本工程通过「用户手动导出账单 CSV → 小程序导入」+「手动/语音记账」获取交易数据，绝不宣称自动同步。

## 需求边界（2026-07-14 确认）

- ❌ **已放弃**：「自动读取用户微信支付账单 / 后台同步微信交易记录」。微信不向第三方小程序开放此 API，任何小程序都做不到，且违规、过不了审。原需求里"对接微信交易记录"的 **自动同步** 部分正式取消。
- ✅ **保留的数据来源**（互不依赖，可单独使用）：
  1. **手动记账**（核心闭环）
  2. **语音记账**（核心闭环，需同声传译插件）
  3. **微信账单 CSV 手动导出后导入**（可选增强——用户在微信内主动导出文件，再选文件导入，**非 API 读取**）
- ✅ **不受影响**：统计对比（昨日/上周/本周/上月/年度 + 环比/同比/占比/预算）完全基于本地账目数据，不依赖微信账单，照常可用。

## 运行步骤（约 10 分钟）

1. **导入工程**
   打开「微信开发者工具」→ 导入项目 → 选择本目录。AppID 先用「测试号」或你自己的小程序 AppID。

2. **配置云环境**
   - 工具顶部点「云开发」→ 开通 → 记下**环境 ID**。
   - 打开 `app.js`，把 `globalData.env` 改成你的环境 ID。
   - 打开 `project.config.json`，把 `appid` 改成你的小程序 AppID。

3. **创建数据库集合**
   云开发控制台 → 数据库 → 新建集合 `records`，权限设为**「仅创建者可读写」**。

4. **部署云函数**
   分别右键 `cloudfunctions/login`、`aggregate`、`importBill` → 「上传并部署：云端安装依赖」。

5. **添加语音插件（语音记账需要）**
   微信公众平台 → 设置 → 第三方设置 → 插件管理 → 添加「微信同声传译」（provider appid `wx069ba97219f66d99`）。不添加也能运行，只是语音按钮会提示未启用。

6. **真机预览**
   点「预览」用手机微信扫码。记一笔 → 看报表 → 导入账单，全程可跑。

## 功能说明
- **极简记账**：记账页选分类 → 输金额（大键盘）→ 保存，默认今天/支出，3 步完成。
- **语音记账**：点🎤说「昨天花 35 块吃麦当劳」，自动解析时间/金额/用途并**预填**，确认后保存（不自动存，防误记）。
- **报表**：切换昨日/上周/本周/上月/年度，看收支、环比、同比、分类占比、月度预算进度。
- **导入**：微信内「我→服务→钱包→账单→导出」另存为 CSV，账单页「导入微信账单」选文件即可批量入账。

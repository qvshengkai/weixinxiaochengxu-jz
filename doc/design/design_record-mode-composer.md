# 首页多模式记账输入台 - 交互设计稿

> 版本：v1.2  
> 创建时间：2026-08-06  
> 状态：首版已实现

## 1. 视觉方向

延续当前产品的紫粉渐变：输入台使用白色半透明卡片、淡紫描边和粉紫选中态；图标仅做功能提示。内容区保持首页原有信息密度，空态只提供短引导，不引入聊天人物或大面积装饰背景。

## 2. 结构

```text
首页内容
└─ 多模式记账输入台（固定，位于 TabBar 上方）
   ├─ 模式标签（可横向滚动）
   │  ├─ ✨ AI 记账（默认）
   │  ├─ ✏️ 手动记账
   │  ├─ ⇩ 账单导入
   ├─ AI 引导/示例（仅 AI 模式且输入为空时）
   └─ 输入行
      ├─ 文本输入框 / 已转写文字
      ├─ 识别按钮（有文本时）
      └─ 麦克风按钮
```

## 3. 模式切换规则

| 操作 | 页面反馈 | 调用/跳转 |
| --- | --- | --- |
| 点击 AI 记账 | 选中标签，展示示例和文本输入 | 不请求接口 |
| 点击手动记账 | 短暂选中反馈 | `openEntry()`，金额键盘聚焦 |
| 点击账单导入 | 短暂选中反馈 | 跳转账单页，并带 `autoImport=1` |
| 点击麦克风 | 同语音输入 | `startVoice()` |
| 点击识别 | 按钮 loading | `parse-agent`，成功后调用现有 AI 回填 |

输入台在手动面板、录音面板打开时隐藏，避免双层底部组件抢占触摸区；关闭后恢复到上次选中的模式。

## 4. 文案

| 位置 | 文案 |
| --- | --- |
| AI 输入占位 | 例如：昨天午饭 32 元，打车 18 元 |
| AI 空态引导 | 一句话告诉我这笔账，我来帮你填好 |
| AI 提交 | 识别 |
| 录音完成 | 已转成文字，确认后点击识别 |
| 多笔识别提示（MVP） | 检测到可能有多笔账，请逐笔确认 |

## 5. 实现映射

| 目标 | 复用模块 | 需要新增/调整 |
| --- | --- | --- |
| AI 回填 | `fillFromAi`、`parse-agent`、`createAiRecordPatch` | 将 AI 文本输入从手动面板上移到输入台 |
| 手动账单 | `openEntry`、分类选择、数字键盘 | 无领域模型变化 |
| 语音转写 | `startVoice`、`asr` 云函数 | 回写输入台 `aiText`，不自动识别 |
| 导入 | `pages/bill`、`bill-parser` | 账单页识别 `autoImport=1` 后调用既有选择文件流程 |

不改变 `records` 字段和既有类别数据结构。页面状态只新增 `composerMode`、`composerExpanded`（如需要）等 UI 状态。

## 6. 交互原型

可在浏览器中打开 [record-mode-composer.html](../prototype/record-mode-composer.html) 查看：标签可切换，AI 示例可填充，语音和导入显示对应反馈，手动模式展示应打开的金额/分类面板。

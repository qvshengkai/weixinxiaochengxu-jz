# 首页记账底部弹层 - 详细设计

> 版本：v1.0
> 创建时间：2026-07-27
> 状态：交付实现
> 最后更新：2026-07-27

## 1. 目标与边界

### 目标

把首页从「常驻分类网格 + 常驻键盘」改为更接近微信输入体验的轻量入口：首页负责展示和触发，用户点击后才进入记账输入面板。

### 不在本次范围

- 不修改 `records` 集合字段、云函数、统计计算和账单导入。
- 不改语音识别解析规则；语音仍只回填，不自动保存。
- 不重做当前紫粉玻璃感视觉体系。

## 2. 信息架构

```text
首页
├─ 今日摘要 / 空状态
└─ 记一笔输入入口
   ├─ 点击输入栏 → 记账底部面板
   │  ├─ 支出 / 收入
   │  ├─ 金额输入
   │  ├─ 分类 → 分类选择层
   │  ├─ 日期
   │  ├─ 备注
   │  ├─ 语音输入
   │  └─ 保存
   └─ 点击麦克风 → 语音识别 → 打开面板并回填
```

## 3. 首页设计

### 3.1 布局

1. 保持现有自定义导航与紫粉渐变背景。
2. 内容区仅展示「今天支出」摘要与空状态/最近记录，不展示数字键盘和分类网格。
3. 页面底部、TabBar 上方固定输入入口：
   - 左侧：白色圆角输入栏，文案为 `＋　记一笔`。
   - 右侧：独立圆形 `🎤` 按钮。
4. 输入栏和麦克风分别是独立点击目标，触控尺寸不小于 44px。

### 3.2 行为

| 操作 | 结果 |
|---|---|
| 点击「记一笔」 | 从底部弹出记账面板，默认支出、今天、默认分类、空金额 |
| 点击首页麦克风 | 启动现有语音识别；成功后打开记账面板并回填字段 |
| 点击语音识别失败/插件不可用 | 保持首页，沿用现有错误提示 |

## 4. 记账底部面板

### 4.1 出现与关闭

- 面板从 TabBar 上方滑入；页面其余部分显示半透明遮罩。
- 点遮罩、`取消` 或右上角 `×`：关闭面板，**不保存**。
- 关闭时保留本次输入仅限当前页面会话；重新点击「记一笔」时可继续输入。保存成功后才清空表单。

### 4.2 面板结构与优先级

1. 顶栏：左 `取消`、中 `记一笔`、右 `×`。
2. 支出 / 收入切换：紧凑分段控件。
3. 金额：最大视觉元素，初始显示 `¥ 0.00`。
4. 字段行：分类、日期、备注。
5. 纯数字键盘：`1-9`、`.`、`0`、`⌫`，不放语音、日期或保存。
6. 底部操作：左侧独立语音按钮，右侧主按钮 `保存`。

### 4.3 字段规则

| 字段 | 默认值 | 编辑方式 | 规则 |
|---|---|---|---|
| 收支类型 | 支出 | 点击切换 | 切换后显示对应类型分类，分类重置为该类型首项 |
| 金额 | 空 | 数字键盘 | 正数，最多两位小数，保持现有金额上限 |
| 分类 | 支出首项 | 点击字段 | 打开分类选择层 |
| 日期 | 今天 | 点击字段 | 调用原生日期选择器 |
| 备注 | 空 | 文本输入 | 可选，不改变现有落库字段 |

## 5. 分类选择层

### 5.1 交互

1. 用户点击面板中的 `分类` 行。
2. 在同一页面上方弹出第二层分类面板，不跳转新页面。
3. 顶部显示 `‹ 返回` 与标题 `选择分类`。
4. 以 4 列网格展示当前收支类型的分类；当前选中项高亮。
5. 用户点击任意分类后：
   - 更新分类字段；
   - 自动关闭分类选择层；
   - 回到原记账面板和金额键盘。
6. 点击分类层外的遮罩或 `‹ 返回`：不修改分类，回到记账面板。

### 5.2 分类来源

复用 `utils/categories.js` 的 `EXPENSE_CATS` 与 `INCOME_CATS`；不在页面内重新维护分类列表。

## 6. 语音输入

- 首页与记账面板各放一个 `🎤` 按钮，均调用同一套现有识别逻辑。
- 识别中显示现有录音遮罩；点击遮罩停止。
- 识别成功后回填金额、收支类型、分类、日期、备注，并打开记账面板。
- 识别结果以轻量提示卡展示；用户可继续手动修改任一字段。
- 严格保持「仅回填、不自动保存」。

## 7. 保存与异常

| 场景 | 表现 |
|---|---|
| 金额为空或 0 | toast：`请输入金额`，面板保持打开 |
| 保存中 | 主按钮禁用或显示加载态，避免重复提交 |
| 保存成功 | toast：`已记录`；关闭面板；恢复默认表单 |
| 保存失败 | toast：`保存失败`；面板与用户输入保持不变 |
| 语音插件不可用 | 沿用现有明确说明，不影响手动记账 |

## 8. 视觉规范

- 背景、渐变、玻璃卡片、文字颜色沿用当前 `app.wxss` 变量与现有紫粉色值。
- 首页入口：白底、淡紫阴影、圆角胶囊；麦克风使用蓝紫渐变。
- 弹层：`#FBF8FD` 浅色底，顶部圆角，使用柔和分割线 `#EEE6F3`。
- 主保存按钮：沿用 `#B79CEA → #F3A6C4` 渐变。
- 分类选中：浅粉背景 + 同色外圈，不使用刺眼的纯色填充。

## 9. 实现建议

### 页面状态

```js
{
  entryVisible: false,
  categoryPickerVisible: false,
  type: 'expense',
  categoryId: 'food',
  amountStr: '',
  happenAt: Date.now(),
  note: ''
}
```

### 事件清单

| 事件 | 说明 |
|---|---|
| `openEntry` / `closeEntry` | 打开或关闭主记账面板 |
| `openCategoryPicker` / `closeCategoryPicker` | 打开或关闭分类层 |
| `selectCat` | 选择分类并自动返回主面板 |
| `toggleType` | 切换收支类型与分类集合 |
| `startVoice` | 首页和面板共用的语音入口 |
| `onKey` | 仅处理数字、小数点、退格 |
| `save` | 沿用现有写库逻辑，成功后关闭面板 |

## 10. 验收清单

- [ ] 首次进入首页看不到数字键盘和分类网格。
- [ ] 首页的「记一笔」和麦克风均可独立点击。
- [ ] 点「记一笔」后出现底部面板，点遮罩/取消可关闭。
- [ ] 数字键盘仅包含数字、小数点和退格。
- [ ] 分类选择在当前页面完成，不出现新页面跳转。
- [ ] 选分类后自动回到金额输入。
- [ ] 首页和弹层的语音入口均可回填表单，且不自动保存。
- [ ] 保存成功关闭面板；保存失败保留输入。

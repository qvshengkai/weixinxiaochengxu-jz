# 首页底部布局优化 - 待确认

> 版本：v1.1
> 创建时间：2026-08-04
> 状态：已实现
> 最后更新：2026-08-04

## 已定位问题

- 自定义 TabBar 层级高于记账弹层，导致底部键盘与保存区可能被 TabBar 遮挡。
- 首页输入入口预留高度大于 TabBar 实际高度，导致底部出现额外视觉空隙。

## 拟定调整

1. 首页输入入口固定在 TabBar 实际顶部，统一使用同一份底部安全区计算。
2. 记账弹层与分类选择层从 TabBar 上方出现，而不是从屏幕最底部出现。
3. 弹层打开时隐藏或降级 TabBar，避免两个固定底部组件同时竞争空间。
4. 收紧数字键盘、语音与保存按钮的间距，让保存按钮贴近键盘且保持安全区。

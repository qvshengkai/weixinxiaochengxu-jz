## 审查范围

首页记账、语音识别云函数、分类管理和隐私说明的新增改动。

## 待处理项

1. P0：ASR 本地配置文件包含长期云密钥；应立即在腾讯云控制台轮换已暴露密钥，删除本地后备读取，仅使用云函数环境变量。
2. P1：一句话识别请求没有传 `VoiceFormat`，该字段为腾讯云接口必填参数；应根据录音输出明确传 `pcm`。
3. P1：录音上传到云存储后没有删除，但隐私说明承诺语音不留存；识别成功或失败均应清理对应文件，并把第三方 ASR 处理方写入隐私说明。
4. P2：ASR 云函数目录缺少与其他云函数一致的 `package.json`，部署时应明确声明 `wx-server-sdk` 依赖。
5. P2：默认「餐饮」与新加的「零食」均包含关键词「奶茶」；当前同分时按定义顺序选择餐饮，导致零食不会被自动命中。需要为重叠关键词定义唯一归属或明确优先级。
6. P2：页面任意隐藏时都会调用录音停止方法，即使并未处于录音状态。应先判断录音状态，避免产生无意义的停止调用和控制台错误。
